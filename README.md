# ROADSTER: AFTERBURN

A browser-based 3D arcade prototype featuring a high-speed Roadster escape, police pursuit, vehicle damage, and local leaderboard.

## Run locally
Open `index.html` in a modern browser. Three.js is loaded from a CDN, so an internet connection is required.

## Deploy on Vercel
Import this repository into Vercel as a static site. No build command is required; use `.` as the output directory.
